# DREDGE · 航行与油漆匠扩展

为 DREDGE Mac 制作的本地扩展研究与源码仓库。当前实现为 **油漆匠整合版 2.2.0**：在小马罗原版油漆匠中选择三套原创旗面和船漆，同时保留显形目的地轮盘、航行设置和货舱整备。

本公开仓库用于代码阅读、讨论和后续协作，**不包含游戏本体、可运行 app、游戏 DLL、反编译导出或个人存档**。构建扩展需要自行提供匹配的正版 Mac 游戏文件；当前运行隔离合同还绑定原 Mac 工作区，其他克隆目录不能直接运行。

## 给接手的 agent

先读 [协作边界](AGENTS.md) 和 [当前状态](docs/当前状态.md)。公开仓库不代表授权修复问题或继续开发。

| 路径 | 内容 |
|---|---|
| `src/Painter/` | 原生油漆匠第三页、三主题、独立船顶与船壳、每存档外观状态 |
| `src/MerchantTravel/` | 七目的地显形轮盘、解锁与落点检查、隔离身份 |
| `src/VoyageExperience/` | 航行设置、钓鱼调整、重复货舱整备与恢复 |
| `src/Weaver/` | 固定目标方法的离线补丁器与语义审计 |
| `src/CosmeticPack/` | 素材加载、渲染覆盖，以及历史 F8 外观版 |
| `src/NativeProbe/`、`src/MerchantTravelQA/` | 隔离测试工具，不进入正常可玩包 |
| `tools/` | fresh 构建、启动守卫和离线测试 |
| `assets/JinkeSkins/` | 深海拉面、罐头章鱼、月航信使三套原创旗图及配色 |
| `research/` | 分阶段研究、设计与交付记录 |

## 当前体验与限制

原生油漆匠服务第三页提供三主题，船顶、船壳分别搭配；刷漆使用原版耗时流程，选择原版项目即可恢复相应外观。新版不使用 F8 外观窗口。

显形轮盘覆盖七目的地；航行设置和货舱整备延续 2.1.0。新版使用独立游戏身份与进度副本，不覆盖 Steam 正式进度。含扩仓功能的隔离档不要直接搬回原版。

偶发加载停滞、显形失败后本局停用、航行偏好与存档回退不完全同步等问题仍保留，详见 [当前状态](docs/当前状态.md)。本轮只整理发布，没有修复游戏问题。

## 构建与验证

环境、离线检查和重建方式见 [构建与验证](docs/构建与验证.md)。只兼容已分析的 **Mac v1.5.4 prod / build 2993**；包元数据可能显示 1.5.3，以原程序集指纹为准：

```text
Assembly-CSharp.dll SHA-256:
a071ffebe51514af5f661055f126a5041acda127623ee7c681c6ef2233a24729
```

Windows、Intel Mac、手柄和完整剧情未完成验证。离线测试、程序回调、Mac 实机观察与完整物理输入分别记录，不能互相替代。

已有本地可玩副本的用户：连接存放项目的 T7 Shield，先启动并登录 Steam，退出其他 DREDGE，再双击 `output/DREDGE 油漆匠整合版 — 启动.command`。启动器和 app 只留在本机，GitHub 不提供下载。旧 F8 版恢复步骤见 [历史使用说明](research/外观版历史使用说明.md)。

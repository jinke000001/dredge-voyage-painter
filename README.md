# DREDGE · 航行与油漆匠扩展

为 DREDGE Mac 制作的本地扩展研究与源码仓库。**最新源码为双船型灯座修补预览版 `2.3.0-preview.4`（R3）**，稳定游玩基线仍是油漆匠整合版 2.2.0。

新版在造船坞加入“船型外观”，仅针对五级船（Boat5），可选深海异教渔船、赛博改装渔船、折线渔舟或恢复原版。两款原创船型各有四种受损状态；R3 为真实普通/高级前灯增加主题支架，保留原灯、旗帜、装备挂件、物理和既有航行能力。油漆匠三主题、七目的地显形轮盘、航行设置与货舱整备继续保留。

**验收边界：**早期 MVP 已完成隔离实测及用户鼠标流程确认；R2 用户游玩反馈功能基本实现，同时报告前灯与船体断开。R3 的构建、资源与离线配准检查已完成，**修补后的游戏内观感仍待用户试玩**。当前预览沿用用户授权从 2.2.0 复制的独立进度及后续游玩，原 2.2.0 app 和源进度保留。详细阶段记录见 [船型外观 MVP](research/船型外观MVP.md)。

本公开仓库用于代码阅读、讨论和后续协作，**不包含游戏本体、可运行 app、游戏 DLL、反编译导出或个人存档**。构建扩展需要自行提供匹配的正版 Mac 游戏文件；当前运行隔离合同还绑定原 Mac 工作区，其他克隆目录不能直接运行。

## 当前体验与限制

原生油漆匠服务第三页提供三主题，船顶、船壳分别搭配；刷漆使用原版耗时流程，选择原版项目即可恢复相应外观。新版不使用 F8 外观窗口。

显形轮盘覆盖七目的地；航行设置和货舱整备延续 2.1.0。油漆匠与双船型版使用各自的独立身份；双船型版保留用户已授权的进度副本，不覆盖 Steam 正式进度。含扩仓功能的隔离档不要直接搬回原版。

偶发加载停滞、显形失败后本局停用、航行偏好与存档回退不完全同步等问题仍保留，详见 [当前状态](docs/当前状态.md)。本次同步只整理现有实现与说明，没有另行修复这些问题。

```text

a071ffebe51514af5f661055f126a5041acda127623ee7c681c6ef2233a24729
```

Windows、Intel Mac、手柄和完整剧情未完成验证。离线测试、程序回调、Mac 实机观察与完整物理输入分别记录，不能互相替代。

已有本地可玩副本的用户：连接 T7 Shield，先启动并登录 Steam，退出其他 DREDGE。最新预览入口为 `output/DREDGE 双船型灯座修补版 2.3.0 R3 — 启动.command`；旧 2.2.0 入口为 `output/DREDGE 油漆匠整合版 — 启动.command`，两者进度身份不同。启动器和 app 只留在本机，GitHub 不提供下载。旧 F8 版恢复步骤见 [历史使用说明](research/外观版历史使用说明.md)。

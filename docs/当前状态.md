## 既有验证范围

来源是 2026-10-19 的 `research/油漆匠接入与验证.md`，不是本次新游戏验收：外观替身测试 41 项、真实 Yarn VM 离线测试 58 项、Weaver 75 项；Mac 记录涵盖原生服务回调、分页布局、冷启动读回、换档隔离和最终包到主菜单。完整物理鼠标流程、手柄、全部船型及破损未逐项通过。

本次不启动游戏或重建 app。原始输出和截图留在本地；本轮公开检查与离线测试结果见 `公开整理记录.md`。

## 已知问题与讨论候选

以下来自既有审查，本轮尚未修复或新增游戏复现：

1. 偶发启动加载停滞：曾发生长时间加载，重启后成功，根因未查清。
2. 显形失败后本局停用：`TravelController.CommitTravel`、`OnTeleportComplete`、`Fail` 等路径可能遗留状态或错误标记，需回标题恢复。成功抵达记录不覆盖失败恢复。
3. 航行设置与存档回退不完全同步：货舱等级随游戏存档，其他偏好在按存档哈希分组的 sidecar 中；写入失败或回档时可能不一致。
4. 验证缺口：四至八级货舱、全部船型、手柄、英文布局、长期捕获统计，以及完整纯物理输入流程。

详见 `research/航行体验审查汇报.md`。该文关于 README 和启动器的描述是当时观察；根 README 已更新，历史文档保留原日期。

建议后续先区分稳定性修复和新体验。天气只有研究；早期传送计划里的 F9、六目的地和默认参数也不是当前决定。具体目标与实施授权由用户另行确认。

## 本地与远程边界

没有游戏也能读源码、审阅规则、提出方案。生产组件及部分测试需要匹配的正版 Mac 游戏文件；运行验收还需要 Mac、Steam 与授权隔离进度。当前 ProfileContract 将输出根目录固定在原 T7 工作区，其他目录不能直接运行，移植需另行审查。云端阅读与离线测试不能写成 Mac 实机通过。
